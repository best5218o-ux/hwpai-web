# HWP AI 어댑터 — 웹판·휴대폰 앱(PWA)

**바로 열기: https://best5218o-ux.github.io/hwpai-web/**

- 한글 프로그램 없이 HWP를 HWPX로 바꾸고, 원본과 대조해 검증합니다.
- 변환·검증·민감정보 확인은 모두 이 브라우저(WebAssembly) 안에서 일어납니다. 파일은 서버로 보내지 않습니다(이 주소는 화면 파일만 내려 줍니다).
- 휴대폰: 위 주소를 크롬으로 열고 메뉴 → 「앱 설치」(아이폰 사파리는 공유 → 홈 화면에 추가). 한 번 연 뒤에는 인터넷 없이도 변환됩니다.
- 2026 공공 AI 대전환 챌린지 세션1 출품작 「HWP AI 어댑터 - HWP를 AI가 바로 읽고 HWPX로 바꾸는 어댑터」(대전서부소방서 문화119안전센터 김영민)의 웹판입니다. 데스크톱 휴대용판·소스는 공공 GitLab(gitlab.aigov.go.kr/best5218/hwpai)에 있습니다.
