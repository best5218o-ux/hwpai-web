# hwpai 웹 — HWP→HWPX 변환·검증·민감정보 확인 (브라우저 전용)

서버 없이 **이 폴더의 정적 파일만으로** 동작합니다. 파일은 브라우저 밖으로 나가지 않습니다(네트워크 호출 0건 — `검증결과.md` 참조).
변환 엔진은 데스크톱판과 같은 rhwp 0.9.0-local WebAssembly, 판독·검증서·민감정보·내보내기는 데스크톱판 hwpai 본체 Python 코드를 Pyodide(브라우저용 Python)로 그대로 돌립니다.

## 쓰는 법
1. `index.html` 을 엽니다(아래 「배포」). 처음 3~4초 엔진을 올립니다.
2. HWP 파일이나 **폴더를 통째로 끌어놓거나** 「파일 선택」「폴더 선택」을 누릅니다. 하위 폴더까지 찾아 `.hwp`(와 `.hwpx`)만 처리합니다.
3. 표에서 변환·검증 판정(PASS/WARN/FAIL)·민감정보 상태·실패 사유(한국어)를 봅니다. 「검증서」로 파일별 검증서를 봅니다.
4. 민감정보 「확인 필요」 문서는 「확인 대기 열기」에서 검출 구간(종류별 색 밑줄)을 보고 항목별 「민감정보임/아님」을 고릅니다(일괄 선택·키보드 지원). 결정은 문서 SHA-256 기준으로 이 브라우저에만 두며 **값(전화번호 등)은 저장하지 않습니다.** 「결정 파일 받기」는 데스크톱판 `sens apply` 로 적용할 수 있는 형식입니다.
5. 「결과 전체 zip」: `<폴더>/….hwpx`, `_검증서/…(md·json)`, `이관대장.csv·xlsx·jsonl`, `요약.md` — 데스크톱판 결과 폴더와 같은 구성입니다. 「Markdown·JSON 내보내기」: 본문.md·구조.json·chunks.jsonl·images (AI 폴더용을 켜면 확인 필요 문서는 제외하고 목록에만 올림).

## 배포 (공개 배포는 하지 않았습니다 — 아래는 안내)
- **파일 열기만**: `index.html` 더블클릭(`file://`). 엔진 파일을 `payload/*.js`(gzip+base64)에서 읽으므로 폴더 전체가 있어야 합니다.
- **정적 호스팅**(행정망 내부 웹서버·nginx·IIS·Apache·사내 Pages): 이 폴더를 그대로 올립니다. `vendor/` 의 `.wasm` 이 `application/wasm` 으로 나가고 gzip/brotli 압축이 켜져 있으면 가장 빠릅니다. 서버 로그에는 정적 파일 GET 만 남고 문서 내용은 오가지 않습니다. 이 경우 `payload/` 는 지워도 되지만(`manifest.js` 는 SHA-256 대조용이라 남김) 지우지 않아도 무방합니다.
- **HTTPS/로컬호스트 권장**: 일부 브라우저 기능(SHA-256 대조 `crypto.subtle`)은 보안 컨텍스트에서만 켜집니다. 안 켜져도 변환은 됩니다(대조만 건너뜀, 화면에 표시).
- 소스 갱신: `python3 tools/build.py`(py/·js/worker.js 를 묶음 파일로 다시 만듦). 외부 도구·네트워크 불필요.
- 요구 브라우저: WebAssembly·Web Worker·DecompressionStream·`<dialog>` 지원(최신 Chrome·Edge·Firefox·Safari 가 기능상 요구를 충족하나, **시험은 Chromium 한 가지에서만** 했습니다). 메모리: 일꾼 1개당 약 300~400MB.

## 휴대폰·태블릿 앱(설치형 웹앱, PWA)
- 이 폴더를 기관 내부 웹서버(HTTPS)에 올리면 휴대폰 크롬·사파리에서 주소를 열고 「앱으로 설치」(아이폰은 공유 → 홈 화면에 추가)로 **앱처럼 설치**할 수 있다. 아이콘·전체 화면·한국어 이름 「HWP AI」.
- 처음 한 번 열 때 엔진 파일(약 25MB)을 기기에 저장하고, 그다음부터는 **인터넷이 끊겨도** 앱이 열리고 변환·검증·zip 내려받기가 된다(`sw.js`, 같은 출처의 정적 파일만 저장). 문서 파일은 저장·전송하지 않는다.
- 휴대폰 화면에서는 끌어놓기 대신 「파일 선택」을 쓰고(폴더 선택은 숨김), 결과는 zip 으로 내려받는다. 데스크톱 크롬·엣지에서 설치하면 HWP 파일을 이 앱으로 열 수 있다(파일 연결).
- 시험(2026-11-11, Chromium Pixel 7 에뮬레이션, 로컬 서버): 설치 조건 오류 0, 캐시 25개 파일, 표본 4건 변환 PASS·zip 내려받기 → 오프라인으로 바꾼 뒤 다시 열어 4건 변환 PASS·zip, 외부 요청 0. 실제 휴대폰 기기·iOS 사파리는 시험하지 못했다(`tools/e2e/run_mobile_pwa.js`).

## 데스크톱판 대비 못 하는 것 (솔직한 한계)
- **전체 드라이브 훑기·폴더 감시(자동 변환)·이어하기 대장**: 브라우저는 사용자가 고른/끌어놓은 파일만 볼 수 있고 디스크를 훑거나 감시할 수 없습니다. 처리 기록은 탭을 닫으면 사라집니다(zip 으로 내려받아 보관).
- **탐색기 우클릭 메뉴·바탕화면 끌어놓기 .bat·AI 연결(MCP)·AI 질문(ask)**: 없습니다. (AI 로 넘기는 길 자체가 없으므로 「AI 노출 차단」은 내보내기의 AI 폴더용 옵션으로만 적용됩니다.)
- **격리 사본(`_격리/`)**: 만들지 않습니다(원본은 사용자 디스크에 그대로 있으므로). 이관대장의 격리 행에 「검증서」 경로가 비는 것이 데스크톱판과 다른 유일한 칸입니다.
- **등급 파일(CSV)·예외허용**: 없습니다(정책 선택은 옵션에서 가능).
- **속도**: Python 을 WebAssembly 로 돌려 데스크톱판보다 느립니다(실측 111건: 데스크톱 18.6초, 웹 1일꾼 31.7초·2일꾼 26.2초). 아주 큰 파일은 메모리 한도에 걸릴 수 있습니다.
- **시간 한도**: 한도를 넘으면 그 일꾼만 끊고 새로 띄웁니다(데스크톱판 Node 일꾼과 같은 방식).
- 암호가 걸린 문서의 **실제 열기**는 시험하지 못했습니다(시험용 암호 문서가 코퍼스에 없음) — 검증결과.md 참조.
