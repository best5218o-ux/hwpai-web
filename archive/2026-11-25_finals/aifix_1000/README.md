# 검증서로 AI 자동 수정 — 정부 HWP 1,000건 실증 (결선 개선·보완, 2026-11-23)

검증서가 이미 내던 「AI가 고치려면」 수정안(기존 기능)을 다듬은 **오류 수정**입니다. 새 기능은 없습니다.

## 방법 (`aifix_1000_run.py`)
1. 정부 HWP 1,000건의 정상 변환본(검증 PASS 999건, FAIL 1건은 제외)에 오류를 하나씩 일부러 넣는다: 글 바뀜 332 · 표 칸 글 바뀜 335 · 문단 빠짐 332.
2. 검증서(audit)로 다시 검사한다.
3. 검증서 수정안(`replace_text_한번에`)만 그대로 적용하고 다시 검사한다. 사람이 손대지 않는다.

## 결과 (`aifix_1000_result.json`)
| | 건수 |
|---|---|
| 오류를 넣은 문서 | 999 |
| 검증서가 오류로 잡음 | 998 |
| 수정안만으로 다시 PASS | **968 (97%)** |
| 사람 확인으로 넘김(끼울 자리를 한 곳으로 정할 수 없음) | 27 |
| 고친 뒤에도 FAIL | 3 |
| 검증서가 놓침(오류를 넣었는데 PASS) | 1 (`0719`, 표 칸 글 바뀜) |

처음 돌렸을 때 약 70%였고, 원인 4가지를 기존 기능의 오류로 고쳤다:
① 긴 문단·여러 문단 표 칸을 통째로 바꾸려다 실패 → 달라진 곳만 좁혀 짝 짓기(`explain._small_pairs`)
② 문단을 끼우기만 할 때 수정 보고서 KeyError(`edit.report_md`)
③ 줄바꿈이 든 문단을 끼울 자리로 못 찾음(`edit.insert_hwpx`, 공백·줄바꿈 무시 대조)
④ 새로 끼운 문단에 앞 문단 글 조각이 따라 들어감
그리고 검증서 차이 글 잘림 300/400자 → 2,000자(`audit`). 자동 시험 66개 통과.
