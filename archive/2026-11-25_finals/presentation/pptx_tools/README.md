# 발표자료 PPTX 만들기 도구 (결선 준비, 2026-11-23 ~ 24)

발표자료 실물(PPTX)은 이 저장소에 두지 않습니다. 여기에는 만드는 도구와 측정 기록만 둡니다.

| 파일 | 하는 일 |
|---|---|
| `build.py`, `build2.py` | 바탕 PPTX에 고해상도 장표 그림과 7·8쪽 영상을 넣고 자동 재생 설정. 영상 위에 투명 판을 덮어 화면을 눌러도 다음 장으로 넘어가게 함 |
| `post.py` | 글자가 남은 장을 그림으로 바꾸고(다른 PC 글꼴 문제 방지), 부록 삭제, 발표자 메모 넣기 |
| `fixpkg.py` | 한쇼의 「손상된 문서」 경고 해결 — 노트 마스터에 테마 사본을 따로 줌 |
| `t.py`, `ap2.py`, `snd.py` | 한쇼 영상 시작 지연 시험용 PPTX 만들기(소리 유무·코덱·예열·화면전환 소리) |
| `../영상지연_글꼴_측정기록.md` | 한쇼·파워포인트 실측 결과 |

경로는 작업 당시 임시 폴더 기준이라 그대로는 실행되지 않습니다(기록용).
