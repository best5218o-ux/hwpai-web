# 7·8쪽 영상 시작 지연, 손상 경고, 글꼴 — 실측 기록 (2026-11-23 ~ 24, 사용자 PC)

## 1. 한쇼 2024 영상 시작 지연
측정법: 영상 화면에 경과 시간을 찍은 시험 영상을 PPTX에 넣고, 슬라이드 도착 약 3초 뒤 화면의 숫자를 읽어 「도착 → 재생 시작」 시간을 계산.

| 조건 | 시작까지 |
|---|---|
| 소리 있음 · AAC 48kHz 모노(당시 사용본) | 약 2.6초 |
| 소리 있음 · AAC 44.1kHz 스테레오 | 약 2.5초 |
| 소리 있음 · MP3 | 약 2.3초 |
| 소리 없음(같은 해상도) | 약 0.3초 |
| 소리 없음 · 640px 작은 영상 | 약 0.3초 |
| 앞 장에서 소리 영상을 먼저 재생(예열) 후 소리 있는 영상 | 약 2.4초(효과 없음) |
| 무음 영상 + 같은 장에 소리만 든 작은 영상 | 무음 영상도 약 2.9초로 늦어짐 |
| 무음 영상 + 화면전환 소리(WAV) | 약 2.4초로 늦어짐 |

결론: 한쇼는 같은 장에 소리가 하나라도 있으면 영상 시작이 약 2.5초 늦는다. 인코딩·해상도로는 줄지 않는다. 소리를 빼면 0.3초.
- v9.0(지연 1초 설정)은 3~4초, 지연 0으로 바꾼 해설음성판은 약 2.5~2.7초, 무음판(지연 0.7초)은 약 1.0~1.4초.

## 2. 파워포인트(Office16) — 2026-11-24
v10.1 해설음성판: 복구 안내 없이 열림, 18장. 7쪽 영상은 도착 후 약 1초 안에 자동 재생(소리 있는 영상인데도 한쇼보다 빠름). 8쪽 제목·「동작 설명 영상」 보임. 화면 눌러 8→9쪽 넘어감. 소리 출력 자체는 화면으로 확인 불가(미확인).

## 3. 한쇼 「일부 텍스트, 이미지, 개체 등이 손상된 문서」 경고
- v9.0 포함 모든 PPTX에서 발생. 슬라이드를 0장으로 줄인 파일에서도 발생 → 슬라이드가 아니라 공통 부분이 원인.
- 노트(발표자 메모)를 모두 뺀 파일은 경고 없음. 노트 마스터가 슬라이드 마스터와 같은 theme1.xml 을 함께 쓰는 것이 원인.
- 노트 마스터에 테마 사본(theme2.xml)을 따로 주면 경고 없음(발표자 메모 유지). 도구: `fixpkg.py theme2`.

## 4. 다른 PC 글꼴
- 글꼴(Noto Sans KR)이 없는 PC 대비: 화면 글자를 모두 3840×2160 그림으로 고정. 슬라이드 XML의 글자(a:t) 0개, 글상자 0개 확인. 7쪽은 배경·제목을 그림으로 깔고 영상·투명판(눌러서 넘기기용) 유지, 8쪽 제목은 영상과 정지 화면에 넣음.
- 발표자 메모만 글자로 남음.

## 5. 영상 위를 눌러도 다음 장으로
전체 화면 영상이 클릭을 가로채 다음 장으로 안 넘어가던 문제 → 영상 위에 투명 사각형(ClickThrough)을 덮음. 한쇼·파워포인트 모두 8→9쪽 넘어감 확인.
