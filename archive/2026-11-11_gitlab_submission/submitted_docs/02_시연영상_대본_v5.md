- 1,000건: 기본 정책(확인 요청)으로 1,000건 모두 변환, 판정 PASS 999·FAIL 1(0195), 확인 필요 266(본문 66·문서 속성만 200). 62건: PASS 62, 확인 필요 44. 306건: PASS 292·WARN 12·FAIL 0. 이전 차단형 정책(pii)의 880·120은 선택 정책 수치이며 화면에서 보이지 않는다.
