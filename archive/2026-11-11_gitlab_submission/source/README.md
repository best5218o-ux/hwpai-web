# HWP AI 어댑터 - HWP를 AI가 바로 읽고 HWPX로 바꾸는 어댑터

**한글 없이 HWP를 HWPX로 바꾸고, 변환 결과를 원본과 대조해 검증하며, AI가 바로 읽고 쓰는 어댑터**

2026 공공 AI 대전환 챌린지 세션1(자유주제 · 행정업무 효율화) 출품작 · 참가자 대전서부소방서 문화119안전센터 김영민(개인) · 명령 이름 `hwpai` · 라이선스 MIT

> 한컴 한글 2024·kordoc·hwpConverter 등과 같은 표본·같은 잣대로 잰 결과와 이 프로그램만의 장점은 [성능 비교 평가서](docs/benchmark.md)(그래프판 [PDF](docs/benchmark.pdf))에 모았다.

- Topic: 공고의 「2026 공공 AI 대전환 챌린지 세션1」 주제 — gitlab.aigov.go.kr 의 Topic 이름 `2026_challenge_session_1`(화면 제목 「2026년 공공 AI 대전환 챌린지_세션1_자유주제」)
- 프로젝트 공개 범위: 비공개(심사위원 열람용)
- 접속 주소: 서버가 필요 없는 내 컴퓨터용 프로그램이다. 화면은 실행한 PC 안에서만 열린다(`http://127.0.0.1:8765/?t=〈접속 열쇠〉`, 실행 창에 주소가 나온다).
- 실행 파일: `hwpai-portable-win64.zip`(Windows 휴대용 폴더, 설치·관리자 권한·인터넷 불필요). 저장소의 릴리스 첨부 또는 제출 메일로 받은 같은 파일(SHA256: `SHA256SUMS.txt`).

## 실행 방법 (Windows)
1. `hwpai-portable-win64.zip`을 풀고 `check.bat` → 마지막 줄 「결론: 사용할 수 있습니다.」 확인.
2. 탐색기에서 `sample_data` 폴더를 `hwpai.bat` 아이콘 위에 끌어다 놓는다 → `sample_data_hwpx변환` 폴더와 요약이 열린다(합성 문서 4건 모두 변환·PASS, 개인정보 꼴 시험 문서 1건은 「확인 필요」로 표시).
3. `hwpai.bat`을 두 번 누르면 브라우저 화면이 열린다. 폴더(하위 폴더 포함)·파일 여러 개를 화면에 끌어다 놓고 「변환 시작」 → 진행 막대·남은 시간·파일별 판정 → 「결과 폴더 열기」「이관대장 열기」「FAIL만 보기」.
4. 명령: `hwpai.bat convert D:\문서함`, `hwpai.bat drop D:\가 D:\나`, `hwpai.bat audit 원본.hwp 변환.hwpx`, `hwpai.bat ask 문서.hwp "질문" --profiles 모델.json`.
5. 자세한 절차·LLM 연결·제약 사항: `docs/guide.md`(구동안내서 PDF와 같은 내용).

## 기능
| 기능 | 결과 |
|---|---|
| 폴더째 HWP→HWPX (한글 불필요) | 원본 폴더 구조 그대로 변환본, 원본은 읽기만. 같은 폴더를 다시 넣으면 이어하기, 실패 파일 격리 |
| 변환 검증서 | 변환 엔진과 다른 판독기로 원본을 직접 읽어 글·표 칸·그림·각주 대조 → PASS·WARN·FAIL과 차이 위치 |
| 이관대장 | 파일별 원본·변환본 SHA-256, 엔진 판, 판정, 이유 → `이관대장.xlsx`(「사람확인목록」 시트) |
| 끌어놓기 화면 | 화면 전체가 끌어놓기 자리, 목록 미리보기, 보안등급(기본·공개 자료·엄격) 선택, 실시간 판정 표 |
| 민감정보 확인 요청 | 변환·검증은 막지 않고, 개인정보 꼴·문서 속성(작성자 등)은 이관대장에 「확인 필요」로 적는다. AI에 보이는 길(질문·MCP·AI 폴더 내보내기)만 사람이 하이라이트 화면에서 확인한 뒤 열린다 |
| Markdown·JSON·RAG 조각 내보내기 | 표·그림 참조·각주·머리말을 담은 Markdown, 표 격자·병합·그림 해시·속성을 담은 구조화 JSON, 근거 쪽 번호가 붙은 조각. 명령·화면·MCP 모두 가능. 확인 전 문서는 AI 폴더에 쓰지 않는다 |
| 서식 보존 치환·양식 채우기 | HWPX에서 글만 바꾸고 서식은 그대로, 변경 보고서와 되읽기 검증을 남긴다(원본은 덮어쓰지 않음) |
| 변환 전후 시각 비교·AI 친화도 점검 | 쪽별 SVG를 나란히 보는 HTML 보고서, 병합 칸·그림 설명·글상자·개요 점검 보고서 |
| 문서 속성 점검 | 작성자·단체·키워드 등 속성을 보여 주고 변환본에서 비울 수 있다 |
| 폴더 감시·우클릭 변환(선택) | 새로 들어온 HWP를 자동 변환·검증. 탐색기 우클릭 메뉴는 기본 꺼짐(.reg 생성, 적용·제거 명령) |
| 문서에 질문(모델 비종속) | OpenAI 호환 모델 여럿에 같은 근거로 질의, 핵심 값(숫자·단위·날짜·기관명) 일치 비교, 근거 밖 값 경고 |
| AI 앱 연결(MCP) | 도구 8개(read_hwp·get_tables·search_chunks·convert_to_hwpx·audit·export_doc·replace_text·fill_form), 같은 확인 요청 적용 |
| 웹판·휴대폰 앱(PWA) | **바로 열기: https://best5218o-ux.github.io/hwpai-web/** (휴대폰 크롬에서 열고 「앱 설치」, 한 번 연 뒤에는 인터넷 없이 변환) · 같은 파일이 `hwpai-web.zip` — 브라우저 안에서만 변환·검증·민감정보 확인·내보내기, 파일은 서버로 가지 않음. 기관 내부 웹서버에 올려도 같다 |

## 확인한 것
- 실행: 사용자의 Windows PC 2대(행정망 PC·외부망 PC)에서 작동 확인, Claude 데스크톱에서 MCP 도구 호출 성공(2026-11-04·11-08).
- 행정망 온AI 실측(2026-11-09): 행정망 PC에서 변환(PASS, 글 4,119자·표 5개 차이 0)한 본문을 업무망 온AI 에이전트에 첨부해 질의 — Solar Pro 4 7/8·HCX-GOV-THINK-30B 8/8, 30문항 Solar Pro 4 28/30·K-EXAONE 25/30. 두 서비스 모두 외부 MCP 등록 기능이 없어 첨부 방식으로 쓴다.
- 한글 2024 실기(2026-11-11): 공개 저장소 문서 2,286건의 변환본을 한글로 열어 모두 열림, 한글이 센 쪽 수 2,234/2,234 원본과 같음, 한글이 저장한 HWPX 끼리 글 2,224/2,227 완전 일치, 한글이 원본 HWP는 못 열지만 변환본은 여는 문서 46건.
- 모델: 챌린지 주최 측이 세션1·2에 지원하는 업스테이지 Solar Pro 4 API(`solar-pro4`, databus.kr 공지 2026-10-26)와 공통기반 지원 모델군인 네이버 HyperCLOVA X(`HCX-005`), 2개 사 모델에서 실제 구동 확인(외부망 공개 API, 2026-11-10). 설정 파일의 `base_url`·`model`만 바꿔 교체하고, 키는 환경변수로 직접 넣는다.
- 정확도: 공개 보도자료 HWP 1,000건(2017~2021) 공개 지정 PASS 999·FAIL 1, 기본 정책(확인 요청)으로 1,000건 모두 변환, 확인 필요 266건 / 2022~2024년 27개 기관(행정안전부 포함) 보도자료 62건 공개 지정 62 PASS / 합계 30개 기관 1,062건 / 공개 저장소 구조 시험 문서 306건 PASS 292·WARN 12·FAIL 0.
- 0195: npm 배포판 엔진(0.8.7)이 변경 추적으로 지운 글을 옮기고도 통과로 표시한 거짓 PASS를 검증서가 찾아냈고, 엔진을 rhwp 소스 빌드로 바꿨다. 한글 PDF로 화면 글이 hwpai 변환본과 같음을 확인했으나, 원본에 지운 글이 남아 있으므로 공식 판정은 보수적으로 FAIL로 둔다.
- 대량 실제 문서: 공개 보도자료 HWP 10,501건(2013~2026, 60개 기관, 시험 대상 10,492건)에서 변환 99.99%·판정 PASS 99.91%(95% 신뢰구간 99.84~99.95)·FAIL 5건(4건은 변경 추적 문서, 1건은 묶음 안 OLE — 이 1건은 이후 엔진 수정으로 PASS). 합성 문서 9,000건은 따로 센다.
- 한컴 한글 대조: 한글 13(0,0,3901)이 같은 문서를 HWPX로 저장한 결과와 같은 검증기로 나란히 쟀다(한글 변환 성공 438건: 판정 PASS hwpai 437·한글 431·kordoc 436·hwpConverter 355/405, 글 재현율 99% 이상 hwpai 438·한글 435; 한글 자신의 저장이 실패한 8건도 hwpai는 변환). 한글 HWPX로 쪽번호 위치 규칙(마지막 값 적용)을 확정해 반영했고, 변경 추적으로 지운 글은 한글 HWPX가 삭제 표지로 보존하나 화면에는 보이지 않으며 hwpai는 화면 글 기준으로 옮긴다. 채점 규칙은 hwpai가 만든 것이라 중립 심판이 아니다.
- 끌어놓기 화면 자동 시험 26항목 통과(판정이 명령줄과 같음, 원본 불변, 경로 탈출 차단).
- 세 개의 독립된 눈(2026-11-10 오후): ① hwpai 코드를 쓰지 않는 독립 채점기로 한글이 저장한 HWPX 를 기준 삼아 채점 — 같은 438건에서 글 재현·정밀 437/438, 표·칸·그림·OLE·수식·주석 개수 438/438. ② 정적 구조 검사기 `python -m hwpai.hwpxcheck 파일.hwpx`(한글 없이 OWPML 필수 구조·참조 무결성·버전 정보 확인) — 이 검사로 찾은 결함(테두리 0번 참조 55건, 유령 그림 항목 1건)을 고쳐 471건 오류 0, 한글 저장본 463건도 오류 0. ③ 제3자 python-hwpx 의 OWPML 전체 스키마 검사 — 문서 오류 0/446. 한글에서 실제로 열리는지는 위 한글 2024 실기로 확인했다.

## 한계
- 개인정보 검출은 형식 기반이다. 「성명:」 표기 없는 본문 속 이름·주소는 잡지 못하고, 기관 번호와 개인 집 유선 번호를 구분하지 못한다(필요하면 차단형 `--grade-policy pii-strict`).
- 묶음 안 OLE 개체가 사각형으로 바뀌던 엔진 문제는 엔진 소스를 고쳐 다시 빌드해 해결했다(로컬 수정, NOTICE 참조). 변경 추적 문서는 지운 문단·지운 표까지 삭제·삽입 이력을 한컴 표기로 싣는다(시험한 4건에서 보이는 글·지운 글·넣은 글이 한글 HWPX 와 같음).
- 구버전 한글·온나라 웹기안기에서 직접 열어 보는 확인은 하지 못했다(정적 구조 검사만 통과).
